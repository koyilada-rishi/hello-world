# Simple Dashboard

A lightweight dashboard example that uses only HTML, CSS, and vanilla JavaScript. Open `index.html` in any modern browser to view it.

## Features
- Responsive layout with header, KPI cards, and content panels
- Interactive period toggle that updates KPIs and signup chart in real time
- Task manager with add, status update, delete, and clear-completed controls
- Activity feed that records changes you make while interacting with the dashboard
